# Contributing to App Version Manager

Thank you for considering contributing to `creatix/app-version-manager`!

## Code of Conduct

Please be respectful and considerate in all interactions within this project.

## How to Contribute

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Clone & Branch**:
   ```bash
   git clone https://github.com/your-username/app-version-manager.git
   cd app-version-manager
   git checkout -b feature/my-new-feature
   ```
3. **Install Dependencies**:
   ```bash
   composer install
   ```
4. **Run Tests**:
   Ensure all tests pass before making modifications:
   ```bash
   composer test
   ```
5. **Add Tests**:
   When introducing a new feature or fixing a bug, please write corresponding PHPUnit tests in the `tests/` directory.
6. **Submit a Pull Request**:
   Push your branch and open a PR with a clear summary of your changes.

## Coding Standards

- Follow PSR-12 coding style.
- Maintain comprehensive PHPDoc comments on public APIs.
- Keep commits atomic and informative.
