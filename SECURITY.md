# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `creatix/app-version-manager`, please send an email to **hello@creatixinfotech.com** instead of filing a public issue.

All security vulnerabilities will be promptly addressed, and we will coordinate a fix and release disclosure timeline with you.
